# TIRTIL downloads

**User guide:** https://arictan.github.io/tirtil-releases/ (every tool, with screenshots, animations and worked examples)

TIRTIL is a desktop app for XRD, XAFS/EXAFS, Raman, UV-Vis, XRF, SEM and STEM analysis, built for MXene and MAX phase research.

Get the latest version from **[Releases](../../releases/latest)**:

- **TIRTIL-mac-apple-silicon.zip**: Macs with M1, M2, M3 or newer
- **TIRTIL-mac-intel.zip**: older Intel Macs
- **TIRTIL-windows.zip**: Windows 10 and 11

Unzip and open TIRTIL. Once installed, TIRTIL checks this page about once a day and offers each new version itself (Settings › Check for updates).

This repository holds only the downloads; the source code is not public.
